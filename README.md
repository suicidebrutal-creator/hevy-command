# HEVY COMMAND 2.1（iPhone / Research Radar先行版）

## PCで利用
ZIPを解凍し、`index.html` をChromeで開きます。既存2.0.1と同じローカル保存形式です。移行前に必ず2.0.1でJSONバックアップを取得してください。

## iPhoneへインストール
本フォルダを**HTTPS対応の静的ホスティング**（GitHub Pages等）に配置し、iPhoneのSafariでサイトを開きます。共有 → ホーム画面に追加 → Webアプリとして開く → 追加。`file://` で開いた状態ではPWAとしてはインストールできません。アプリを公開してもHEVY CSVやJSONバックアップをリポジトリに置かないでください（公開されるおそれがあります）。GitHub Pagesの場合は公開リポジトリ上のソースが閲覧されます。

## データ移行
PCの「データ管理」→ JSONバックアップ。iPhoneでWebアプリを開き、同じ画面の「バックアップを復元」でJSONファイルを選択。PC/iPhone間の自動同期はありません。古い2.0/2.0.1バックアップも復元できます。研究メモは2.1で出力したJSONに同梱されます。ブラウザデータを削除すると保存内容も消えるため、定期的にJSONを書き出してください。

## RESEARCH RADAR
「公開論文を検索」でEurope PMCの公開APIを呼び出し、PubMed収録の論文を最大15件表示します。公開の検索語句が外部APIへ送信されますが、HEVYのCSVデータやトレーニング記録は送信しません。通信が遮断される環境・オフラインでは検索できません。保存したメモはオフライン閲覧可能です。研究の質や効果を自動判定するものではなく、RCT/レビュー等の表記も索引に依存します。

## 重要な制限
- iPhone Safari実機でのPWAインストール・ファイル操作は未検証です。
- 外部APIのCORS・サービスの稼働状態により検索が失敗することがあります。
- オフライン動作には一度HTTPS環境で起動してキャッシュ作成が必要です。研究検索には接続が必要。
- 1.0/2.0からのJSON互換性は既存の復元方式を使用します。各端末のデータ保存は別です。
